简体中文

本政策适用于 hanlu 发布的 DOMlings Chrome 扩展 0.1.0。扩展的用途是在用户浏览的网页上运行微缩夺旗游戏。

处理哪些数据

扩展的内容脚本可在普通 HTTP 和 HTTPS 网页的顶层运行。生成和更新游戏地形时，它在浏览器本地检查页面中可见的文字、元素布局、尺寸和位置。扩展也在本地处理放置、拖拽、投掷等游戏操作，以及保持地形对齐所需的滚动位置。拖拽期间会临时使用指针位置和时间计算投掷速度。

如何使用、保留与共享

这些信息只用于生成地形、运行游戏和更新操作界面。扩展不把网页原文、输入轨迹或战况持久写入存储，也不建立浏览历史或行为追踪记录。临时游戏状态随页面刷新或关闭而丢弃。

扩展不会把上述信息上传到外部服务器，也不会出售或共享给第三方。扩展不使用这些信息投放广告、建立用户画像或进行分析追踪。DOMlings 对相关数据的使用遵守 Chrome 网上应用店用户数据政策，包括有限使用要求。

控制与联系

你可以在 Chrome 的扩展详情中修改 DOMlings 的站点访问权限，或停用和卸载扩展。如有隐私问题，可通过作者网站联系开发者。

English

This policy applies to version 0.1.0 of DOMlings, a Chrome extension published by hanlu. The extension runs a miniature capture-the-flag game on the page you visit.

What the extension processes

The content script can run in the top-level page of regular HTTP and HTTPS sites. To generate and update terrain, it examines visible text and the layout, size, and position of page elements locally in the browser. It also processes gameplay inputs such as placing, dragging, and throwing units, and uses scroll positions to keep the terrain aligned. Pointer positions and timestamps are used temporarily during dragging to calculate throw speed.

Use, retention, and sharing

This information is used only to generate terrain, run the game, and update its controls. The extension does not save page text, input traces, or game scores to persistent storage, or build a browsing-history or activity-tracking log. Temporary game state is discarded when the page is refreshed or closed.

The extension does not send this information to external servers, sell it, or share it with third parties. It does not use it for advertising, profiling, or analytics tracking. DOMlings uses this information in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Controls and contact

You can manage DOMlings’ site access in Chrome’s extension settings, or disable or uninstall the extension. For privacy questions, contact the developer through the author’s website.
